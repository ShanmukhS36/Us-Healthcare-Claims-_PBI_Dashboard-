Healthcare Claims Analytics Dashboard (Power BI)
****** Project Overview ********

This project focuses on analyzing US healthcare claims data to monitor claim performance, identify denial and pending root causes, and support data-driven decision-making using Power BI.

The solution demonstrates end-to-end analytics from KPI creation to interactive dashboards with slicers, drill-down, and drill-through functionality.

******** Objectives ********

Track overall claims performance

Analyze denials and pending claims using RCA

Identify high-risk providers, regions, and service types

Enable detailed investigation using drill-through pages

 ***** Tools & Skills Used ******

Power BI

DAX (Measures)

Basic Aggregations (SUM, COUNTROWS, AVERAGE)

Iterator Functions (SUMX, AVERAGEX)

Date & Time Intelligence

CALCULATE & FILTER

Data Visualization & Storytelling

Root Cause Analysis (RCA)

 Dashboards Included

Executive Summary

Denial RCA Dashboard

Pending RCA Dashboard

Claims by Region & Service

Provider & Region Denial Analysis

Claims Matrix (Drill-Through Page)

****** Key Features *******

Dynamic KPIs using DAX measures

Interactive slicers (Year, Region, Provider, Service Type)

Drill-down and Drill-through to Claims Matrix

Provider-level and Region-level RCA

Clean, interview-ready dashboard design
